Revisão da atualização

Somente código é atualizado. Dados de jogadores, banco PostgreSQL, Redis, arquivos em var/, .env, configurações do servidor e assets pessoais não são enviados ao GitHub nem substituídos. Faça também um backup externo antes de atualizar o sistema em produção.

Nenhum pacote analisado.

Segurança e reinicialização

Para habilitar a instalação pelo painel, configure a variável de ambiente BROWSERQUEST_UPDATES_ENABLED=1 no processo Node.js e reinicie-o. Por segurança, essa função começa desativada.

Após aplicar uma atualização, reinicie o processo Node.js no aaPanel para carregar o código novo. Bibliotecas npm e alterações de banco de dados devem ser revisadas separadamente.
